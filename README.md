# DA2026_PROJ2_T06_G04

### Project description

This is a greedy algorithm and heuristic based project focused on solving the Compiler
Register Allocation problem. The tool acts as a compiler backend component, mapping
high-level variables (_webs_) to a limited set of physical registers to optimize program
performance and minimize memory access. 

To achieve this, the system implements a tiered approach to allocation, ranging from
_Basic Graph Coloring_ to more advanced techniques such as _Web Spilling_ and _Web Splitting_
to handle register pressure, alongside a custom optimized allocation strategy designed
for enhanced efficiency.
